# SyncSingil Corp. - Secure Microfinance & Digital Ledger

Next-generation microfinance management platform featuring cloud computing and blockchain architecture, complete with dedicated Borrower and Worker/Admin portals.

## Deployment Instructions (Vercel & Supabase)
1. Extract this ZIP archive.
2. Install dependencies: `npm install`
3. Run locally: `npm run dev`
4. Deploy to Vercel: Connect your GitHub repository or use `vercel --prod`.
5. Configure Supabase environment variables in `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
